# GoalPilot Mobile (Android)

Android-клиент на Kotlin + Jetpack Compose. Проект будет создан позже в Android Studio.

## План экранов
1. Вход / регистрация
2. Список целей
3. Просмотр цели (задачи, прогресс, ИИ-декомпозиция)
4. Создание цели
5. Редактирование цели

## Планируемая архитектура
- MVVM, Navigation Compose, Retrofit + Kotlin Serialization
- Хранение JWT в зашифрованном хранилище
